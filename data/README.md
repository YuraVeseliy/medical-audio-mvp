# Данные технического эксперимента

Восемь полностью вымышленных диалогов: два development для технической пробы и шесть замороженных evaluation. Один дополнительный контроль — три секунды тишины.

Аудио создано локально Piper 2023.11.14-2, голос ru_RU-irina-medium. Один голос читает обе роли без произнесения меток. Это не два человека, не реальные пациенты и не клинический корпус. ffmpeg преобразовал WAV в PCM16 mono 16000 Hz. Команды, хеши, длительности и версия генератора — generation.json.

TXT равен входу синтеза. Независимая сверка звука прослушиванием человеком ещё не выполнена. Ожидаемые цитаты и разделы подготовлены разработчиком и не утверждены врачом. Оценка относится к этому небольшому синтетическому набору.

Метрики распознавания считаются на всех словах, включая вопросы. Для извлечения оцениваются только ожидаемые ответы пациента. Техническое совпадение требует верного раздела и равенства цитаты эталону после общей нормализации регистра, ё/е, пунктуации и пробелов. Перефразировки, вопросы, целый разговор вместо факта и несколько фактов одним элементом не проходят этот строгий критерий. Это не оценка клинической правильности.

Данные evaluation не применяются для настройки. Повторные запуски одной записи не являются новыми независимыми случаями.

Повторная генерация: .venv/Scripts/python.exe scripts/prepare_data.py --replace. Перед заменой нужно сохранить исходные данные и объявить новую версию эксперимента. Старый scripts/prepare_data.ps1 сохранён как попытка SAPI, давшая непригодные пустые WAV; итоговые данные подготовлены Python-скриптом Piper.

## Версии итоговой оценки

Исходный набор A в этом каталоге был отложенным для первой конфигурации. После разбора её ошибок A считается материалом разработки/регрессии для нового извлечения. Итоговая оценка нового кандидата проводится на data/evaluation-b11/manifest.json: шесть новых диалогов, 24 эталонных сведения, порядок пар вопрос–ответ в части диалогов изменён до первого LLM-вызова. Предшествующий B1.0 и его ASR-журналы сохранены отдельно, не смешиваются с B1.1. Заморозка и причина изменения записаны в reports/comparison-b11-freeze.json. Ни изменения по итоговым ответам B1.1, ни клиническая валидация не заявляются.
