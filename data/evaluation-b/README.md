# Независимый технический набор B

Шесть новых вымышленных сценариев (24 ожидаемых сведения) зафиксированы после обнаружения проблем свободного цитирования на A и до просмотра любых ответов нового кандидата на B. Время заморозки и SHA256 manifest записаны в `reports/comparison-b-freeze.json`.

Два development-примера из A перечислены в manifest только для технического прогрева. Они не входят в итоговые метрики B и не являются новыми примерами. Аудио этих development-примеров повторно не синтезируется.

Генерация только B:

```powershell
.venv/Scripts/python.exe scripts/prepare_data.py --manifest data/evaluation-b/manifest.json --split evaluation
```

Для синтеза применяется тот же Piper ru_RU-irina-medium, PCM16 mono16000Hz после ffmpeg. Это один синтетический голос, читающий обе роли, без фонового шума и пересечений речи. Условия не представляют все записи пациентов или отделения реанимации. Независимой сверки прослушиванием человеком и медицинской приёмки разметки пока нет.

После просмотра ответов B не используется для выбора подсказки или настройки с последующим заявлением независимой оценки на том же наборе. Новые изменения требуют честной маркировки регрессионной проверки либо нового набора.
