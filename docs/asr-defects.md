# Дефекты и исправления текущей работы

Дата оформления: 25.10.2026. Автор технических проверок - агент. Это не журнал дефектов, лично найденных студентами или врачом. Факты до/после опираются на сохранённые журналы, исходники Git и повторные проверки.

## D01. Захват продолжался при отмене сохранения - прежний дефект, регрессия сохранена

Объект: остановка записи GUI. Среда: Windows/Tkinter с внешним тестовым адаптером микрофона. До исправления диалог пути открывался до остановки захвата. Шаги: начать тестовую запись → остановить/сохранить → отменить выбор файла. Ожидание: микрофон остановлен до диалога, буфер сохранён для повторного выбора. Факт до: во время диалога состояние recording; отмена оставляла захват активным.

Серьёзность: средняя; приоритет P2 до выдачи учебного прототипа. Исправление в прежней реализации: capture останавливает поток до выбора пути, отмена не возобновляет захват. Доказательства прежнего воспроизведения: reports/defects/D01/before.log и after.log. Текущая проверка исправления: T10 проходит. Регрессия текущего приложения: весь набор 15/15. Статус: исправлен в коде, подтверждён с адаптером. Остановка настоящего микрофона остаётся в ручной M04.

## D02. Корректный FLOAT WAV отклонялся - прежний дефект, регрессия сохранена

Серьёзность: средняя, P2. Исправление: реальная проверка аудиопотока/первого кадра через PyAV вместо ограничения wave. Доказательства прежнего воспроизведения: reports/defects/D02/before.log и after.log. Проверка исправления текущей версии: T09 проходит. Регрессия: повреждённый файл по-прежнему отклоняется (T03), сохранение и остальные операции проходят. Статус: исправлен; не означает поддержку любого возможного контейнера и кодека.

## ASR-D03. Дубликат звука допускался в оценку

Объект: validate_dataset в новом эксперименте до 37098d3. Предусловия: один WAV назначен двум ID в разных группах; манифест помечает дубликат. Шаг: валидация набора. Ожидание: отказ до WER. Факт до: ValueError не возникал. Доказательство: reports/asr-tdd/04-red.log, AssertionError ValueError not raised.

Серьёзность: высокая для достоверности сравнения, P2 до основного прогона; не дефект врача/диагноза. Исправление: учитывается отметка подготовки и заново сравнивается фактический декодированный PCM. Проверка: 04-green.log и T13, включая отсутствие отметки в манифесте. Регрессия: 15/15. Статус: исправлен до selection; в реальном человеческом наборе дубликатов не найдено.

## ASR-D04. Недостаточная фиксация весов и условий контроля

Объект: подготовка/проверка runtime и final_control до 37098d3. Обнаружение: статическое ревью. Ожидание: контроль относится к тем же файлам весов, исходникам, данным и потокам. Факт до: сам каталог моделей и папка могли использоваться без обязательного подтверждения фактических файлов; число потоков при контроле не сравнивалось.

Серьёзность: высокая для воспроизводимости, P2. Исправление: каталог с закреплёнными ревизиями/архивами, installed_files с SHA-256, проверка каждого файла и устойчивый fingerprint; validate_control сравнивает источник/данные/веса/потоки. Доказательства: diff и reports/asr-code-review.md. T14 проверяет совпадение и отказ на изменённые потоки/отпечаток. В его red-логе отсутствовал новый API, а не воспроизведён полный реальный контроль с подменённой моделью; это различие важно. Статус: исправлен до selection, все восемь фактических установок проверены.

## ASR-D05. При прерывании worker терялись завершённые строки

Объект: обработка аварии/таймаута в compare_asr до 37098d3. Обнаружение: ревью. Ожидание: сохранить выполненные случаи, явно отметить неполные. Факт до: при отсутствии worker.json итог мог заменить весь результат пустым набором и полными пропусками.

Серьёзность: средняя для отчёта, P2. Исправление: атомарные rows/checkpoint и recover_worker_result. Вход T15: одна сохранённая строка (ошибка 1 из 2 слов) из ожидаемых двух по 2 слова. Итог: строка сохранена, 2 отсутствующих слова учтены отдельно, всего 3/4, кандидат не выбирается. Это искусственная проверка аварийного сценария; настоящий основной прогон не был аварийно остановлен. Статус: исправлен, T15 проходит. Red фиксирует отсутствие нового recovery API, green - ожидаемое поведение.

Основные входы не изменялись, прогон прошёл проверку. Статус: исправлен до selection.

Серьёзность: средняя для отчёта, P2. Исправление в fd73455: признак переносится в итог, таблица отмечает прерывание. Проверка исправления: T15 с assertFalse для признака неполноты. Регрессия: 15/15. Статус: исправлен до selection. Во всех фактических основных прогонах измерение завершено; искусственный checkpoint не подставляется вместо их RSS.

## Ограничения и открытые действия

В автоматических основных/контрольных прогонах не было ошибок выполнения, но есть ошибки распознавания слов. Это ограничение конкретной ASR-модели на входе, а не повод скрывать запись. Примеры приведены в отчёте. Ручные M01–M08, настоящий микрофон, удобство для врача и клиническая приемлемость ещё не подтверждены. Полный пентест не выполнен. Отсутствие новых падений не доказывает отсутствие всех дефектов.
