# Как читать результаты

selection/summary.json фиксирует выбор восьми кандидатов на шести разных записях; chosen_model = gigaam-ctc. final_control выполняется только для уже выбранного кандидата. В control/summary.json поле control_model = gigaam-ctc, а chosen_model = null: нового выбора на контроле нет. Сырой Markdown программы печатает для этого поля None; это не отсутствие выполненной контрольной модели. Полные JSON и фактические строки сохранены без переписывания результатов.

measurements.json содержит все замеры и счётчики ошибок без полных текстов человеческих записей. В freeze/summary сохранены версии, параметры и фактические манифесты весов. dataset-manifest.json описывает частные исходники/эталоны по ID и SHA; голоса в Git не включены. Полные ответы и исходники находятся в отдельном локальном архиве human_dataset_private.zip.

Повторы измеряют вариативность времени, но не дают 18 независимых записей. Нулевой WER двух контрольных диалогов не является доказательством клинической пригодности. Исполнителем технических прогонов был агент; личные проверки студентов имеют отдельные карточки.
