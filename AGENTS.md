# Локальный аудиомодуль ВКР

Актуальная спецификация: docs/homework-plan.md (план нового ДЗ, согласованный в чате). Старый модуль проверки формы находится в истории Git до 853a0c2; его результаты не доказывают качество аудиомодуля.

- Реализовать согласованный объём целиком: запись/импорт, транскрипция, извлечение цитат в жалобы/анамнез, просмотр/правки/экспорт.
- Python 3.11+, Tkinter; внешние библиотеки разрешены для реальной локальной обработки аудио по новой задаче пользователя.
- Только вымышленные данные. Работу врача/студентов, внешнюю приёмку и удалённый CI не выдумывать.
- Небольшие проверки через публичные операции сеанса/обработки. TDD выполняется последовательно с сохранением реальных логов. Допустима подмена внешних моделей/устройств; внутренние модули не мокировать.
- Качество реальных моделей измеряется отдельно от тестов с подставленными ответами.
- Сохранять историю на отдельной ветке. Слияние и публикация требуют доступного репозитория и решения пользователя; текущая работа полностью разрешена локально.
- Коммиты и основная документация на русском. Каждый вывод отчёта должен иметь доказательство или явный статус ограничения/невыполненной проверки.
- Архитектура: model.py (данные), session.py (публичное состояние и обработка), providers.py (границы ASR/LLM/аудио), storage.py (файлы), gui.py (Tkinter).
- Локальные модели и runtime лежат в .runtime/ и не входят в Git. На пользовательские аудиозаписи не распространяется автосбор данных; запись начинается только явным действием пользователя.
